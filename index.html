01 — Full-stack · AI Engineering

Velour — AI-Powered E-Commerce Microservices Platform

A complete UK online marketplace built on a microservices architecture, featuring Vera — an agentic AI shopping assistant. Five independent FastAPI services sit behind an Nginx API gateway with a React single-page frontend; each service owns its own MongoDB database, with JWT auth and atomic stock updates that stay correct under concurrent buyers.

Vera is a multi-agent system built on the Google Agent Development Kit with Mistral Large — a coordinator routes each message to Discovery, Order, Cart or Advisor specialists, and adding to the basket uses a human-in-the-loop two-turn confirmation so the model can never buy on your behalf by mistake.

02 — MSc Dissertation · NLP & Security

Phishing Detection & Adversarial Robustness

A reproducible pipeline over 18,650 labelled emails — 13 statistical and security indicators plus 5,000 TF-IDF features, class-balanced to 22,644 samples. I benchmarked six classical classifiers against a fine-tuned DistilBERT, which reached 97.90% F1 and 99.78% ROC-AUC.

The novel angle is robustness: an automated FGSM adversarial evaluation across attack strengths. At ε = 0.10, DistilBERT's accuracy fell just 0.02 points — versus 26.14 for Random Forest — quantifying which models you can actually trust under attack.

03 — Data Science · Risk Modelling

Transaction Fraud Detection & Risk Modelling

Modelling fraud in 299,695 e-commerce transactions with a heavily imbalanced 2.21% fraud rate. I engineered 21 behavioural and cyclical time predictors in R, then trained an XGBoost model with a weighted ensemble, 44.32 class weighting and a comparison of four categorical encoders.

The model reached 0.974 ROC-AUC and 0.820 PR-AUC, catching 87% of fraud (1,150 of 1,322 cases). Beyond the metrics, it surfaced actionable signals: a failed AVS check carried 9.67% fraud versus 0.76% when matched, and median shipping distance was 626 km for fraud versus 269 km otherwise.

04 — NLP · Deep Learning

Biomedical Entity Recognition Chatbot

A fine-tuned BioBERT model that extracts drug and disease entities from free-text clinical messages using BIO token tagging. Served through a Flask app that loads the tokenizer and model once at startup, runs gradient-free PyTorch inference, and reconstructs subword tokens back into clean, structured JSON.

The prototype adds request validation, rule-based responses, JSONL prediction logging for error analysis, and a lightweight chat interface — with the fine-tuned model published on Hugging Face.
